# Annular – Übersicht

Willkommen im Wiki zur Welt von **Annular**.  
Hier werden alle Charaktere, Orte, Kulturen, Technologien und Ereignisse dieser Geschichte dokumentiert.

> Diese Welt spielt in einer nordeuropäischen Stammesepoche (~100 oder ~900 n. Chr.), kombiniert mit frühen Entdeckungen der Elektrizität und mysteriösen Portaltechnologien — die einzige Abweichung von der historischen Realität.
