# Annular – Übersicht

Willkommen im Wiki zur Welt von **Annular**.  
Hier werden alle Charaktere, Orte, Kulturen, Technologien und Ereignisse dieser Geschichte dokumentiert.

> Diese Welt spielt im Jahr **550 n.Chr. (Vendelzeit)** — proto-skandinavische Germanen im Norden, nomadisches Wüstenvolk im Süden. Kombiniert mit frühen Entdeckungen der Elektrizität und mysteriösen Portaltechnologien — die einzige Abweichung von der historischen Realität. Das Jahreszahl wird intern als Authentizitätsreferenz genutzt und erscheint nicht im Erzähltext.
